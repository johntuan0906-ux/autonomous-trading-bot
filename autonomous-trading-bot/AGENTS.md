## Git & GitHub (đọc kỹ trước khi động vào git)

- Remote dùng **SSH**: `git@github.com:johntuan0906-ux/autonomous-trading-bot.git`
- Trong sandbox của Muse, **`.git` là read-only** → `git commit`, `git push`, `git fetch` và `git clone` (vào workspace) **sẽ thất bại**. Đừng tắt sandbox để lách.
  → Cách đúng: sửa file trong working tree rồi bảo người dùng chạy ngoài sandbox:
  ```
  tools\git-sync.cmd "feat: mo ta thay doi"
  ```
- Cần mạng trong sandbox (tải tài liệu, `git ls-remote`, `pip install`): khởi động lại Muse bằng `tools\muse.cmd` (đã bật `--sandbox-network enabled`, vẫn giữ sandbox + approval).
- Không `git push --force`, không viết lại history, không commit `.env`/file chứa API key.
